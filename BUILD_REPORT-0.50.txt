MOTIVO
------
El equipo de trabajo es Windows y no tiene WSL, Docker ni un host Linux.
La compilación de una ISO Debian requiere live-build, debootstrap y
herramientas Unix que no están disponibles aquí. No se ha simulado ni
falsificado una compilación.

CÓMO COMPLETAR LA CONSTRUCCIÓN
------------------------------
1. Debian 12/13:
     cd desktop
     sudo sh ./prepare-build-host.sh
     sudo sh ./build.sh i386

2. Docker (Windows/macOS/Linux):
     powershell -ExecutionPolicy Bypass -File .\desktop\docker\build-with-docker.ps1
     sh ./desktop/docker/build-with-docker.sh

3. GitHub Actions:
     Ejecutar el workflow «Build MosaicOS ISO (i386)».

Salida esperada:
     desktop/dist/MosaicOS-0.50-i386.iso
     desktop/dist/MosaicOS-0.50-i386.iso.sha256
     desktop/build/i386/build.log

PRUEBA MÍNIMA RECOMENDADA
-------------------------
     qemu-system-i386 -m 2048 -cdrom desktop/dist/MosaicOS-0.50-i386.iso -boot d

Comprobar: escritorio, panel, menú, red, audio, terminal, Firefox,
LibreOffice, un .exe de 32 bits, apagado y reinicio. Después probar el
instalador con un disco virtual vacío.

LIMITACIONES QUE NO CAMBIAN CON LA COMPILACIÓN
----------------------------------------------
- Solo aplicaciones Windows de 32 bits; PE32+ se rechaza.
- Solo arranque BIOS (syslinux/isolinux); sin UEFI de 32 bits.
- La compatibilidad con Wine depende de cada aplicación.
- El instalador Debian no replica automáticamente todo el escritorio Mosaic.
- El rendimiento en 1 GB de RAM no está medido.

Conclusión: la receta de MosaicOS 0.50 está completa y validada
estáticamente. La ISO debe compilarse y probarse en un entorno Linux o
Docker; este informe no afirma que la imagen ya exista o arranque.
